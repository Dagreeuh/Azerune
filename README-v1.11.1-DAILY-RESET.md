# Hotfix v1.11.1 - Réinitialisation quotidienne

Le jeu vérifie désormais la date locale :

- immédiatement au lancement ;
- toutes les 30 secondes ;
- lorsque la fenêtre reprend le focus ;
- lorsque l’onglet redevient visible après une mise en veille.

Au changement de date, les éléments suivants sont réinitialisés :

- progression des trois quêtes journalières ;
- état des récompenses réclamées ;
- coffre quotidien final ;
- date du cycle quotidien.

Les ressources, champions, équipements, campagne, pity, codes et Fragments d’âme sont conservés.
