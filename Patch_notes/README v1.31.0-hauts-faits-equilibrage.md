# Azerune v1.31.0 - Hauts faits et équilibrage initial

## Nouveautés
- Onglet permanent `🏆 Hauts faits`.
- Sept objectifs initiaux avec récompenses uniques.
- Équipements 1★ déterministes pour Valebrume Facile.
- Set Vitalité progressif et Torse Précision pour Histéria.
- Expéditions niveaux 1 et 2 allégées.
- Puissances recommandées abaissées à 500 et 800.
- Aucun Sceau consommé en cas de défaite ou d’abandon.
- Un Sceau est consommé uniquement après une victoire récompensée.
- Sauvegarde migrée au format 19.

## Installation
Copier le dossier `src` à la racine du projet, remplacer les fichiers, vider le cache Vite, puis relancer.
