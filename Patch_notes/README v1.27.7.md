# Hotfix v1.27.5 - Tooltip des sorts

- Cliquer sur un sort lance directement le sort.
- La fiche détaillée ne reste plus ouverte après la sélection.
- Sur ordinateur, la fiche apparaît uniquement lorsque la souris survole le sort.
- Elle disparaît immédiatement lorsque la souris quitte le bouton.
- Sur écran tactile, la fiche n'occupe plus l'écran lors du premier appui.

Copiez `src/pages/BattlePage.jsx` dans le projet puis ajoutez le contenu de `styles-v1.27.5.css` à la fin de `src/styles.css`.
