# Hotfix v1.21.1 - Garantie x10

Ce correctif a été construit depuis les deux fichiers actuels fournis.

## Nouvelle règle

- Chaque tirage conserve 1,5 % de chance d'obtenir un 5★.
- Si les neuf premiers tirages du x10 ne donnent aucun 4★ ou 5★, le dixième garantit au minimum un 4★.
- Sur ce dixième tirage garanti, le taux 5★ reste à 1,5 %.
- Si le jet 5★ échoue, le résultat devient un 4★.
- La pity à 100 invocations reste inchangée.
- Le prix x10 reste à 900 cristaux ou 10 Pierres de foyer.
