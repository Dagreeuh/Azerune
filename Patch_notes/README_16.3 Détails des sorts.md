# Hotfix v1.16.3 — Mécaniques et conseils d’équipement

Copiez le dossier `src` dans le projet, puis ajoutez le contenu de `styles-v1.16.3.css` à la fin de `src/styles.css`.

Chaque compétence affiche désormais :

- sa mécanique exacte ;
- les statistiques qui influencent réellement le résultat ;
- un conseil d’équipement adapté ;
- les dégâts périodiques et pourcentages lorsqu’ils existent ;
- les interactions avec les autres compétences.

Pénitence de Lelianna soigne maintenant réellement à hauteur de 120 % de l’Attaque du lanceur. Les bonus de maîtrise augmentent à la fois les dégâts et ce soin.
