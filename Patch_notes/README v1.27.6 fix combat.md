# Hotfix v1.27.6 - Raccourcis clavier

## Compétences
- `1`, `2`, `3` sélectionnent les compétences correspondantes.
- Appuyer une seconde fois sur la même touche lance la compétence.
- `Entrée` ou `Espace` lance la compétence sélectionnée.
- `Échap` annule la sélection clavier.

## Cibles
- `Q` sélectionne la cible vivante précédente.
- `D` sélectionne la cible vivante suivante.
- Une compétence offensive monocible navigue parmi les ennemis.
- Un soin ou soutien monocible navigue parmi les alliés.
- Les morts sont ignorés.
- Les compétences de zone, d'équipe ou personnelles n'utilisent pas Q/D.

Les raccourcis sont désactivés pendant un tour ennemi, après la fin du combat, pendant la fenêtre d'affinités et dans les champs de saisie.
