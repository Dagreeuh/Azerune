# Chroniques d’Azerune v1.39.0

## Contenu
- Ascension par niveau, Or et Essences.
- Résonance en 5 niveaux grâce aux doublons.
- Doublons après Résonance V convertis en Fragments de sang.
- Sanctuaire de l’Ascension permanent.
- Inventaire global et conversions 10 pour 1.
- Migration automatique de la sauvegarde vers la version 24.

Copiez le dossier `src` dans le projet, puis relancez Vite avec `npm run dev -- --force`.
