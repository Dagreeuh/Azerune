# v1.15 — Équilibrage des Fragments d’âme

Copiez le dossier `src` à la racine du projet et acceptez le remplacement des 3 fichiers.

## Coûts
- Naturel 3★ : 5 fragments (4★), 10 fragments (5★), 20 fragments (6★).
- Naturel 4★ : 4 fragments (5★), 8 fragments (6★).
- Naturel 5★ : 3 fragments (6★).

## Fragment universel 5★
- Le coffre mensuel final accorde 1 Fragment d’âme universel 5★.
- Utilisable uniquement pour compléter une évolution d’un naturel 5★ vers 6★.
- Les fragments personnels sont consommés avant les universels.
- Les fragments excédentaires restent conservés.

Ajoutez le contenu de `styles-v1.15.css` à la fin de `src/styles.css`.
