# v1.17 — Précision et Résistance

Copier le dossier `src` dans le projet et accepter les remplacements. Ajouter `styles-v1.17.css` à la fin de `src/styles.css`.

## Formule
Chance finale = chance de base + Précision - Résistance, limitée entre 15 % et 95 %.

## Résistances
- DPS : 15 % de base.
- Soigneurs : 20 % de base.
- Tanks : 25 % de base.
- Monstre normal Facile : environ 15 %.
- Boss Facile : 30 %.
- Boss Difficile : 45 %.
- Boss HardCore : 60 %.

Les échecs sont indiqués dans le journal de combat avec la chance finale calculée.
