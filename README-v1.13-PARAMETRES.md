# v1.13 - Paramètres et réinitialisation

Un onglet Paramètres est disponible dès le niveau 1.

La réinitialisation demande deux confirmations :
1. validation de l’avertissement détaillé ;
2. saisie exacte du mot `REINITIALISER`.

Les clés `azerune-save`, `azerune-save-daily` et `azerune-tutorial-completed-v1` sont supprimées. Le jeu recharge ensuite le tutoriel et la création du profil.
