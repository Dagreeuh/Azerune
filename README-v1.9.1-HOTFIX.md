# Hotfix v1.9.1 - tours ennemis de campagne

Ce correctif attribue un identifiant de combat unique à chaque ennemi créé par une mission.

Il corrige :
- les trois ennemis affichés avec le même nom ;
- plusieurs badges TOUR simultanés ;
- les jauges ennemies bloquées à 100 % ;
- le message permanent « L’ennemi prépare son action... ».

Copiez le contenu de ce dossier à la racine du projet et acceptez le remplacement des fichiers.
