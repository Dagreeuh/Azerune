# Hotfix v1.9.2 - Récompenses de campagne

- Une mission donne des ressources uniquement lors du premier score obtenu.
- Améliorer le record à 2 étoiles donne la récompense 2 étoiles une seule fois.
- Améliorer le record à 3 étoiles donne la récompense maximale une seule fois.
- Rejouer sans améliorer le record donne uniquement l’XP de combat.
- Le meilleur score reste sauvegardé.
