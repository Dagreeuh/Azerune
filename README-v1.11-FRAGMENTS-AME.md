# v1.11 - Fragments d’âme

Les doublons ne font plus évoluer automatiquement les champions.

## Coûts
- Naturel 3★ : 2 fragments pour 4★, 4 pour 5★, 8 pour 6★.
- Naturel 4★ : 3 fragments pour 5★, 6 pour 6★.
- Naturel 5★ : 4 fragments pour 6★.

## Conditions
- Le champion doit atteindre le niveau maximum de son rang.
- Les fragments requis doivent être disponibles.
- L’évolution est déclenchée manuellement dans Codex ou Équipe.
- Après évolution : niveau 1, XP 0, fragments requis consommés.
- Les fragments excédentaires sont conservés.
