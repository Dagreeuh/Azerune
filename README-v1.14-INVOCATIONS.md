# v1.14 - Invocations x10

- Toutes les invocations x1 et x10 sont accessibles dès le niveau 1.
- Invocation cristaux x1 : 100 cristaux.
- Invocation cristaux x10 : 900 cristaux, soit 10 % de réduction.
- Invocation Pierre de foyer x1 : 1 pierre.
- Invocation Pierre de foyer x10 : 10 pierres, sans réduction.
- Sur un x10, si les neuf premiers tirages ne donnent aucun 4★ ou 5★, le dixième est forcé à 4★ minimum.
- Le taux naturel 5★ reste à 1,5 %.
- Le pity 5★ à 100 invocations reste inchangé et prioritaire.
- Si un 4★ ou 5★ apparaît dans les neuf premiers tirages, le dixième conserve les taux normaux.
