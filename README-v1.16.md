# v1.16 — Maîtrise des compétences

Copier le dossier `src` dans le projet et accepter les remplacements. Ajouter ensuite le contenu de `styles-v1.16.css` à la fin de `src/styles.css`.

## Ressource
- 📘 Tome de maîtrise.
- Coffre hebdomadaire final : 1 Tome.
- Coffre mensuel final : 3 Tomes.

## Coût par amélioration
- Naturel 3★ : 10 000 or.
- Naturel 4★ : 20 000 or.
- Naturel 5★ : 35 000 or.
- Chaque niveau consomme également 1 Tome.

## Niveaux
- Sort 1 : niveau 6 maximum.
- Sort 2 : niveau 5 maximum.
- Sort 3 : niveau 4 maximum.

Les améliorations augmentent réellement puissance, durée d’effet, précision d’effet ou réduisent le cooldown dans le moteur de combat.
