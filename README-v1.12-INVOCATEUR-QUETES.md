# v1.12 - Profil d’Invocateur et cycles de quêtes

## Profil
- Nom demandé une seule fois.
- Niveau d’Invocateur 1 à 60.
- XP obtenue par combats, invocations et quêtes.
- Déblocages : campagne 2, équipement 3, combat libre 4, hebdomadaires 5, invocation x10 8, historique 10, mensuelles 15.

## Quêtes
- Journalières : reset automatique au changement de date.
- Hebdomadaires : reset chaque lundi selon l’heure locale.
- Mensuelles : reset le premier jour de chaque mois.
- Chaque cycle possède trois quêtes et un coffre final.
