# Azerune v1.42.2 - Correctif audit champions

Ce correctif remplace uniquement `src/battle/engine.js`.

Corrections :
- Vaeloria : la Danse exige désormais les trois compétences distinctes. Résonance IV conserve 15 % de jauge sur le tour bonus.
- Mobeen : la première attaque offensive après Disparition est critique, consomme Disparition et reçoit un bonus en Résonance IV.
- Brilith : Orbe d'annihilation calcule désormais ses dégâts avec 4 Charges arcaniques.
- Seraphiel : Jugement conserve 1 charge de Condamnation en Résonance IV.
- Ignovar : Embrasement reçoit une détonation renforcée en Résonance IV.
- Morghast : les réactions gagnent dégâts ou durée en Résonance IV.
- Caelion : Retour temporel réduit les délais alliés de 2 tours en Résonance IV.
- Nashoba : la Goule agit sur toute compétence offensive, y compris les compétences de zone.

Le hotfix v1.42.1 Vol de vie, Seraphiel et Maerys est inclus dans ce moteur cumulatif.
